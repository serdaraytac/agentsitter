What Agentsitter does

agentsitter analyzes your AI agent configs and fixes them.

  • Scores configs (0–100) across clarity, structure, token efficiency, coverage
  • Detects vague rules LLMs can't execute
  • Finds platform-specific bugs (Cursor, Codex, Copilot, Cline, etc.)
  • Auto-fixes issues — not just warnings
  • Optimizes token usage and estimates cost

Works across 13 platforms.

What it catches

  • Vague rules ("best practices", "clean code")
  • Silent truncation (Codex 32KB limit)
  • Wrong frontmatter keys (Cursor vs Cline mismatch)
  • Missing scope definitions
  • Invalid imports (Gemini CLI)
  • Duplicate or conflicting rules

Platform-specific checks

Every check comes from official documentation — not guesswork.

Claude Code

  • CLAUDE_MISSING_BUILD_COMMANDS — no build, test, or lint commands found
  • CLAUDE_COMMANDS_NOT_IN_CODE_BLOCK — commands outside fenced code blocks
  • CLAUDE_PLACEHOLDER_FOUND — unfilled [TODO:] markers in production config
  • CLAUDE_IMPORT_IN_CODE_BLOCK — @-imports inside fenced blocks are literal text
  • CLAUDE_SUBDIR_SPLIT_RECOMMENDED — file over 10 KB with no @-imports

Cursor

  • CURSOR_MISSING_FRONTMATTER — .cursor/rules/ files without YAML frontmatter lose scope control
  • CURSOR_CURSORRULES_LEGACY — .cursorrules no longer documented; migrate to .cursor/rules/*.md
  • CURSOR_RULE_TOO_LONG — files over 500 lines
  • CURSOR_UNKNOWN_FRONTMATTER_KEY — only description, globs, alwaysApply recognized

Codex

  • CODEX_SIZE_LIMIT — hard 32 KiB truncation; content beyond silently dropped
  • CODEX_OVERRIDE_FILE_AVAILABLE — AGENTS.override.md takes precedence over AGENTS.md

GitHub Copilot

  • COPILOT_WRONG_LOCATION — copilot-instructions.md outside .github/ not recognized (critical)
  • COPILOT_INSTRUCTIONS_WRONG_EXTENSION — files in .github/instructions/ must end with .instructions.md
  • COPILOT_INSTRUCTIONS_MISSING_APPLY_TO — path-specific files without applyTo: apply repo-wide

Gemini CLI

  • GEMINI_LARGE_NO_IMPORTS — files over 10 KB with no @-imports
  • GEMINI_IMPORT_IN_CODE_BLOCK — @-imports inside fenced blocks silently ignored
  • GEMINI_IMPORT_INVALID_PATH — imports must use @./, @../, @/, or @~/

Cline

  • CLINE_WRONG_FRONTMATTER_KEY — Cline uses paths:, not globs: (Cursor's key)
  • CLINE_UNSUPPORTED_EXTENSION — only .md and .txt processed from .clinerules/
  • CLINE_AT_IMPORT_NOT_SUPPORTED — @-import syntax not supported

Tools

scan_project    →  find all config files in the repo
analyze_config  →  score each file, see what's wrong
optimize_config →  fix issues automatically, write back to disk

analyze_config accepts a filepath or inline content:

{ "filename": ".clinerules", "content": "# Rules\n..." }

optimize_config returns the fixed content with a before/after score. Add "write": true to save to disk.

{
  "platform": "claude",
  "before": { "overall": 29, "grade": "F" },
  "after":  { "overall": 68, "grade": "C" },
  "changesSummary": ["Rewrote 3 vague rules", "Added Commands section"],
  "optimizedContent": "# CLAUDE.md\n..."
}
